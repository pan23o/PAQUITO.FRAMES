# PAQUITO.FRAMES

Primera versión visual de la web independiente de PAQUITO.FRAMES.

## Arranque local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

## Estado

Esta entrega es la **fase visual 01**. La galería contiene placeholders para definir la identidad de la web. La siguiente fase puede conectar fotografías reales y después añadir backend, base de datos, almacenamiento y `/admin`.
